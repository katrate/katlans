# Katlans VS Code Extension

Official language support for the **Katlans** programming language.

## Features

- **Syntax Highlighting**: Core language keywords, strings, and comments.
- **Run Files**: Provides a "Run" button in the top-right corner of the editor to instantly execute your `.kl` files.

## Requirements

You must have the `katlans` CLI compiler installed on your system and available in your system's PATH.

## Usage

1. Open a `.kl` file.
2. Click the Play (▶) button in the editor title bar.
3. The extension will automatically open a terminal and run your code!
